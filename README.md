# ARAM: Hỗn Loạn Helper

UI tra cứu build lõi và trang bị cho chế độ Hỗn Loạn.

- Đây là dự án cộng đồng, chỉ dùng để tham khảo.
- Dự án không liên kết, tài trợ hoặc được xác nhận bởi Riot Games.
- Tên và hình ảnh trò chơi thuộc chủ sở hữu tương ứng.

Repository public này chỉ chứa bản UI đã build. Source crawler và dữ liệu HTML
thô không được phát hành tại đây.
